# ADR 0003 Recovery request authorization

Status: Proposed operating policy implemented in prepared architecture checks.

The OpsCon calls for recovery request exchange, but ordinary planning/information requests P-IO.01 do not authorize collection. The architecture uses recorded context P-IF.10 plus a scoped authorized support command through P-IO.07 and P-IF.16. An unapproved or wrong-restaurant command must not initiate the request. Waste or surplus information alone neither authorizes collection nor establishes physical suitability. Team and stakeholder confirmation of the operating role and trigger remains required.

Affected entities: P-F.0.4, P-F.0.6, P-IO.07, P-IO.12, P-IF.10, P-IF.16, P-AFR.12.
